## 3. What the wave learned — read before writing prose or proofs

Every substantive defect this wave was a repeat of a named class. They are cheap to avoid and were
expensive to catch.

- **The inherited-claim class fired again, worst of the wave.** BL-202's blank-cell predicate was
  copied VERBATIM from `scripts/validate.sh`, where the regex `\| *\|$|\| *$` had been counting
  EVERY table row (constant ~258, filled or not) since it was written — so the fix's own nag fired
  forever and two of its three user-facing states were dead code. Review caught it only by
  measuring the SHIPPED template (`templates/project-intake.md`) instead of hand-rolled fixtures.
  Fixed in all three files under `# BL-202-INTAKE-PREDICATE` (SYNC SIBLINGS marker). **Fixture the
  real artifact, not a miniature of it** — a green suite over hand-rolled inputs proved nothing.
- **Mutation proofs need a NEGATIVE control.** Two vacuous mutants shipped and were caught only in
  review: one could not source its lib (died at load; "field unchanged" read as success), and one
  was silenced by SIGPIPE — the BL-183 class re-entering the same file the same day it was fixed
  there (`T-utf8-floor-no-sigpipe`). The shape now baked into the bl125/bl132/bl202 suites: feed
  the harness an INTACT copy and REQUIRE a fail, and require empty stderr as proof the mutant ran.
  Copy that shape, not just the excision.
- **Render, don't grep, emitted artifacts.** An unquoted heredoc EXECUTED an instruction's
  backticks at prompt-generation time — the shipped AI prompt carried the command's error text —
  while the source-grep test stayed green over it. The wizard-fixes suite now RENDERS the PROMPTEOF
  body; anything asserting on generated bytes must assert on the render.
- **A byte-level guard is only fail-closed if it consumes all its input.** BL-198's stride-4 BOM
  liar defeated all three vouching surfaces on macOS libiconv (a UTF-32 BOM over a UTF-16 body);
  the fix is the exact U+10FFFF range bound. Its defense-in-depth byte floor was then itself the
  SIGPIPE class. Both are pinned; the exactness residue (one `U+xx00` code unit collapses the
  parity signal) is deliberately kept LOUD, not relaxed, because a dominance ratio reopens crafted
  mis-derivation into a receipt over garbage.
- **`git add -A` is banned in spirit.** It swept four stale root-level scratch files
  (`DOGFOOD-*-PROMPT.md`, `EXECUTIVE-SUMMARY.md` — one an 18-day-stale WRONG status doc) into an
  enforcement commit; a reviewer caught it at the last gate. **Stage explicit paths.** Those four
  files are still untracked at repo root — they are not `.gitignore`d and will re-tempt the next
  `git add -A`.
- **Review metastat:** ~50 findings across six PRs, four of them blocks; every finding verified
  real, several by the reviewer re-running its own attack fixtures against the fix. Two reviewer
  self-corrections are on the record in the round transcripts (a BL-181 predicate claim, a
  "no test in any lane" claim narrowed to the true survivor). Re-measure claims — the reviewer's,
  the entry's, and your own from earlier in the same session.
